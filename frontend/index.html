How accurate is this scoring system, really?

Every news read a real prediction uses gets logged the moment it happens, then checked against what the price actually did once that same horizon elapses — a live, growing record, not a retroactive claim (we don't have a historical news archive to validate against, so we build this forward from today instead).

Loading…

Which news sources actually deserve trust?

Every individual source's own directional calls are tracked independently — not the aggregate reading, each outlet's own record. A source needs at least 20 evaluated calls before its reliability is shown as meaningful; proven-reliable sources genuinely count for more in every prediction going forward, proven-unreliable ones count for less, and new/unproven sources stay neutral until they've earned a real track record.

Settings

Preferences, data management, and diagnostics.

Default risk profile

Used as the starting selection whenever you open Predictions — you can still change it per-prediction.

News direction sensitivity

How strongly a day's news needs to lean bullish or bearish (on a -100 to +100 impact scale) before it counts as directional at all, rather than neutral. This is a starting guess, not a value proven against real outcomes yet — lower it to see more news counted as directional; raise it to require stronger, less ambiguous language. The is what should eventually settle this with real evidence.

Autonomous pick notifications

When enabled, your browser will notify you if the app's autonomous "best pick right now" changes to a different ticker — even while you're on another tab. This requires your browser's own notification permission, and only works while this app is open in a tab somewhere (closing the browser entirely, or stopping the server, pauses it — it's not a phone push notification).

Get real evidence accumulating faster

Accuracy tracking, source reliability, and news evidence only build for tickers you've actually predicted on — left alone, that grows one ticker at a time as you check things manually. This runs real predictions across the entire scanner universe (~120 tickers) at once, in the background, so many more real 5-day (or longer) evidence "clocks" start ticking sooner. It doesn't make time pass faster — nothing can — it just makes better use of the time that does pass. This can take a while (real training, one ticker after another) and will use noticeable CPU while it runs.
